# Práctica 06: Sketches de WhatsApp Business

La página separa los sketches por rol. **Administrador Business** muestra únicamente el flujo administrativo. **Rol de usuario** muestra bienvenida, verificación del número, perfil, Chats, grupos y las secciones de Nuevo chat, Novedades, Comunidades, Llamadas y Configuración.

Las capturas 6 y 7 se representan juntas como una sola pantalla de Configuración desplazable. Las pantallas de Nuevo chat y Llamadas usan contenido genérico, sin nombres ni números personales.

El prototipo usa modo oscuro con fondo negro e interacciones verdes. No requiere paquetes ni servicios externos.
